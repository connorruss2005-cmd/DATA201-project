1. Airbnb Cleaning Automation

- Converted the existing Airbnb cleaning process into a reusable function:
  clean_airbnb(df)

- The function receives a DataFrame instead of reading a fixed file directly.

- Kept the month_year column so that new monthly datasets can be identified
  after cleaning.

- Added validation for required columns.

- Standardised numeric and text columns.

- Added checks for:
  - missing latitude/longitude
  - invalid coordinate ranges
  - duplicate rows

Reason:
The cleaning process can now be reused automatically for future monthly
Airbnb datasets without manually changing file paths or code.


2. Koordinates API Automation

- Converted the existing area-code mapping process into reusable functions:
  get_area_code()
  add_area_codes()

- Existing area-code mappings can be reused.

- Only coordinates that have not already been mapped are sent to the
  Koordinates API.

- Existing mappings with missing area codes are treated as incomplete
  and can be queried again.

- Removed the fixed 28,390-row check from Deliverable 5.

- The new version checks that the row count before and after mapping
  remains the same.

Reason:
The API mapping can now work with datasets of different sizes, including
new monthly Airbnb data, without manually changing the code.
