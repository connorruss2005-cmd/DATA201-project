## Dataset

### Source

This project uses the June 2026 New Zealand `listings.csv` dataset from
Inside Airbnb. The dataset contains information about Airbnb listings,
hosts, locations, prices, availability, and reviews.

Due to its large size, the dataset is stored locally and is not included
in this GitHub repository.

### Column descriptions

| Column | Description |
|---|---|
| id | Unique identifier for the Airbnb listing |
| name | Name or title of the listing |
| host_id | Unique identifier for the host |
| host_name | Name of the host |
| neighbourhood_group | Larger geographical grouping, when available |
| neighbourhood | Area in which the listing is located |
| latitude | Latitude of the listing |
| longitude | Longitude of the listing |
| room_type | Type of accommodation offered |
| price | Price per night |
| minimum_nights | Minimum number of nights required for a booking |
| number_of_reviews | Total number of reviews received |
| last_review | Date of the most recent review |
| reviews_per_month | Average number of reviews received per month |
| calculated_host_listings_count | Number of listings associated with the host |
| availability_365 | Number of days the listing is available during the next 365 days |
| number_of_reviews_ltm | Number of reviews received in the last 12 months |
| license | Licence or registration information, when available |
