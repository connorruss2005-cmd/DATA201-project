Dataset overview and Data Dictionary

Source
* **Dataset Name:** Airbnb Listings Data (`listings.csv`)
* **Source:** [Inside Airbnb](http://insideairbnb.com/get-the-data/)
* **Format:** CSV

Key Columns and Definitions

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| 'id' | Integer | Unique identifier for the Airbnb listing |
| 'name' | Text | Name\title of the listing on Airbnb |
| 'host_id' | Integer | Unique identifier for the host |
| 'host_name' | Text | Name of the host of listing on Airbnb |
| 'neighbourhood_group' | Text | The standardized city/district name |
| 'neighbourhood' | Text | The suburb inside the city/district |
| 'latitude' | Float | Geographic latitude coordinate of the listing |
| 'longitude' | Float | Geographic longitude coordinate of the listing |
| 'Room_type' | Text | Type of space offered |
| 'Price' | Currency/Text | Nightly price for the listing in local currency |
| 'minimum_nights' | Integer | Minimum number of nights required for a booking |
| 'number_of_reviews' | Integer | Total count of reviews the listing has recieved |
| 'last_review' | Date | Date of the recent review on the listing |
| 'calculated_host_listings_count | Integer | Total number of listings the host has in this region | 
| 'reviews_per_month | Float | Average number of reviews per month | 
| 'availability_365' | Integer | Number of days the listing is available for booking within the next 365 days |
| number_of_reviews_ltm | Integer | Total counts of reviews received in the last twelve months |
| 'license' | Text | License, permit, or registration number |
