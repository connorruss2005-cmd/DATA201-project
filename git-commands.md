# Git Commands Memo

## Get the latest main branch
‵‵‵bash
git switch main
git pull origin main
‵‵‵

## Create a new branch
‵‵‵bash
git switch -c branch-name
‵‵‵

## Check changes
‵‵‵bash
git status
‵‵‵

## Save changes
‵‵‵bash
git add .
git commit -m "Describe the change"
‵‵‵

## Push the branch to GitHub
‵‵‵bash
git push -u origin (branch-name)
